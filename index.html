Touche pour poser les points

Glisse les ronds pour épouser la surface. Touche un carré pour ajouter un point, double-touche un rond pour le retirer. Menus repliés, le pavé de flèches ajuste au pixel près (le point choisi, sinon toute la forme) ; touche son centre pour le changer de côté.

Formes

Touche d’abord une forme sur la scène, ou choisis-la dans l’onglet Formes.

Une fois tes formes calées sur le mur, touche « Copier la scène » puis colle le texte dans une conversation avec Claude. Il te rend une vidéo prête pour la clé USB, sans aucune interface à l’écran.

Les formes sont gardées dans ce navigateur. Les images et vidéos sont à recharger à chaque ouverture.
